# 做新包

每个部分都带着这份内容，所以拿到任何一个音色包，就能做一个和它没有关联的新包（这叫自传播）。这里是抽象的规格：写什么、怎么写、谁能看什么、怎么查重。这里没有也不该有一个完整的示例角色：示例会被照抄，新包就成了示例的影子。

## 流程

1. **说出想要的属性。** 用设计词表里的标签和场景，加上自己的话（想要什么样的声音、拿来做什么）。基础部分的 `clean-room` 命令把它们和这里的规格、空白模板放进一个目录：净室输入。这一步不读来源包。
2. **净室里的做包 agent 写文字。** 新开一个会话或子 agent，只把净室输入这个目录给它，让它写新包的文字内容：音色描述、配音指引、示例台词（设计出来的声音再加设计来源）。已经读过来源包角色内容的 agent（例如把来源包装成了 skill 的那个会话）不能写这一步：它读到的内容会漏进新写的文字里，净室就破了。
3. **备素材。** 自己的录音，或者设计一个声音。素材不从来源包里拿。
4. **做包，同时查重。** 用基础部分的做包命令，把素材和第 2 步写出的文字做成新包，并把来源包交给它：在花钱的步骤之前，先把新包的文字和录音同来源包比一遍（查重）。

命令和选项的正本在基础部分的 `SKILL.md`「做音色包」一节。

## 净室：谁能看什么

- 净室里的做包 agent 只看净室输入：这份规格（`spec/`：这份说明和三个字段的格式 `fields.json`）、空白模板（`template/`）、使用者说的属性（`attributes.json`）、任务说明（`BRIEF.md`）。
- 它不看来源包的任何角色内容：清单里的描述、配音指引、示例台词、转写、参考音频、脚本。也不向使用者或别的 agent 要这些。
- 使用者的话原样交给它，不改写，也不替使用者补充来源包里有的东西。使用者要是把来源包的原文贴进了属性，这一步拦不住，由查重在最后拦。

## 每个字段怎么写

格式的正本是 `FORMAT.md`（清单的 schema 在 `schema/manifest.schema.json`），净室输入里的 `spec/fields.json` 是从 schema 里摘出来的这三个字段的格式，字数、条数的上限看它。这里只说写什么。下面只给写法的形状（尖括号里是要你填的），不给现成的句子：现成的句子会被照抄，新包就成了它的影子。

**音色描述**（`direction.description`）：一两句，说这个声音听起来是什么样：年龄感、音色的质地、气质、语速。写声音，不写人：不写真人的名字、角色名、作品名。
形状：「<年龄感>、<质地>的<音色>，语速<快慢>，<像什么、给人什么感觉>。」

**标签和场景**（`direction.tags`、`direction.scenes`）：只能从词表里选（设计词表、场景词表，在基础部分的 `vocab/`）。净室输入的 `attributes.json` 里已经列了使用者选的，原样放进 `direction.json`，不增不减。

**配音指引**（正文，放进 SKILL.md 的最后一节）：写给配音的 agent 看，它拿台本配音时怎么用这个声音。分小节（模板里有）：语气、节奏、情绪、口头禅和常用的语气词、适合和不适合的场景。每节一到几句，只写想要的效果，不写某个模型的指令语法。写「怎么变」比写「是什么」有用：情绪变了，声音往哪边变。
形状：「<什么时候>，<声音往哪边变>。」「<什么场合>用，<什么场合>不用。」

**示例台词**（`sampleLines`）：三到十句这个声音会说的话，各句的内容、长度、情绪拉开。可以带舞台提示，写法同基础部分的台本标记（词表在 `vocab/cues.json`）。不抄现成的台词、名言、歌词、作品里的对白。
形状：「<舞台提示><这个声音会说的一句话>」，舞台提示可以没有。

**设计来源**（`designSource`）：只有设计出来的声音才写。记下设计时用的那句描述，用的模型和日期也一并记（字段见 `FORMAT.md`）。设计时试听用的台词（`auditionLines`）不用你写，也不要编：它们是设计那一边记下的原文，由调用你的 agent 写进清单。用录音做的包不写。

**交付**：写好的内容放进 `output/`，文件名照模板：`direction.json`、`guidance.md`、`sample-lines.json`、`design-source.json`（只有设计出来的声音才有）。

## 查重

做包的最后一步，目的是不让来源包的文字和录音被原样搬进新包。规则的正本是基础部分的 `lib/duplicate-check.mjs`（比什么、怎么比、阈值和标定的依据），这里只说大意：

- 比新包的文字（音色描述、配音指引、示例台词、设计来源、脚本）和新包的录音。不比标签和场景（从词表里选的，同一类声音本来就选得一样）、名字、变更说明、读音词表、转写（读同一句话不是抄；录音有没有被搬用由指纹管）。
- 文字用最长公共子序列的 F1（ROUGE-L）和连续词组的重合比例；录音用音频指纹找「同一段录音」。不比说话人像不像：同一个配音演员给几个角色配音是正常的。
- 超过阈值报 `duplicate_detected`，`details` 里写是哪一项、重合多少、阈值多少。
- 查完不留来源包的记录：来源包的名字、包 ID、路径，不写进新包、日志和报告。

## 新包的记录

新包用新的包 ID。清单的 `madeWith.baseVersion` 只记做包时用的基础部分的版本，不记来源包。
