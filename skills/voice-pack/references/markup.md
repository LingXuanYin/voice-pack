# 台本标记

这一份是基础部分的参考，`SKILL.md` 第 4 节指到这里。标记的名单在 `vocab/markup.json`；精确的语法和解析程序在 `tools/` 里的台本标记解析。

| 写法 | 作用 |
|---|---|
| `# 标题` | 一章的开头 |
| `[pause 0.6s]` | 停顿，单位是 `s` 或 `ms`；省略时长就用默认值 |
| `[voice:<声音>]` | 从这里起换一个声音 |
| `[slow]…[/slow]`、`[fast]…[/fast]` | 放慢、加快；可以嵌套；没有结束标记的，管到这一行结束、下一个语速标签（`[slow]`、`[fast]`、`[emphasis]` 任何一个）的开始标签、或者下一个 `[voice:]` 为止；中间的 `[pause]` 不切断它（`[slow]你好[pause 1s]我走了` 两段都慢）；有结束标记的，`[pause]` 切断它 |
| `[emphasis]…[/emphasis]` | 强调 |
| `[spell]…[/spell]` | 逐字拼读 |
| `（耳语）`、`*笑*` | 舞台提示，转成语气提示（耳语、笑、叹气、生气等）；管从它出现的地方，到这一行结束，或者下一个同类的提示出现为止，换一行、换声音就清掉；停顿（`[pause]` 或提示里的停顿）不切断它（`（生气）你好[pause 3s]我走了`，「我走了」照样是生气的）；新的情绪或风格提示整个换掉旧的，放慢、加快和 `[slow]`、`[fast]`、`[emphasis]` 是一类，新的出现旧的就结束；笑、叹气这样一下子的声音（`*笑*`、`（叹气）`）例外，只管紧跟在它后面的那一段话，这一段以后回到它出现以前管着的（`（耳语）你好[pause 1s]*笑*哈哈[pause 1s]再见`，「哈哈」是笑，「再见」是耳语）；括号里不是整个都是提示的内容怎么处理，见 `references/dub.md` 的「一句话是怎么变成合成的」第 2 步 |
