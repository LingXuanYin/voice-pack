# 台本标记

这一份是基础部分的参考，`SKILL.md` 第 4 节指到这里。标记的名单在 `vocab/markup.json`；精确的语法和解析程序在 `tools/` 里的台本标记解析。

| 写法 | 作用 |
|---|---|
| `# 标题` | 一章的开头 |
| `[pause 0.6s]` | 停顿，单位是 `s` 或 `ms`；省略时长就用默认值 |
| `[voice:<声音>]` | 从这里起换一个声音 |
| `[slow]…[/slow]`、`[fast]…[/fast]` | 放慢、加快；可以嵌套；没有结束标记的，到这一行结束 |
| `[emphasis]…[/emphasis]` | 强调 |
| `[spell]…[/spell]` | 逐字拼读 |
| `（耳语）`、`*笑*` | 舞台提示，转成语气提示（耳语、笑、叹气、生气等）；括号里不是整个都是提示的内容怎么处理，见 `references/dub.md` 的「一句话是怎么变成合成的」第 2 步 |
