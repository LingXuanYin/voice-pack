# qwen-audio-3.1-tts-flash

This model is not used for dubbing in the normal flow; dubbing always uses scene3 (`scene3.md`). Its voice-design capability is still declared by adapters, but no flow of the base part calls it. When adding a reference in another language to a pack, it is only an option: on a platform that can name the model, the user may choose to first have it read a passage in this language from the pack's original reference and then use that as the reference; by default it is not used, and scene3 dubs across languages (`references/character-voice.md`「Add a reference segment in this language」; for the readings see `scene3.md`「Cross-language and accent」).

This file only says how to use the model itself and is not tied to a platform; limits a platform adds are written in that platform's adapter. The last section, "Fallback when scene3 is unavailable", covers what you need to know when dubbing is temporarily switched to this model. The source of a claim is kept in `models/qwen-audio-3.1-tts-flash.basis.md`, under the number of the mark `[^bN]` at the end of the claim, and the kinds of source are as in `scene3.md`「How the source is written.」[^b1].

## What it accepts

- The same request does not guarantee the same voice.[^b2]

## Fallback when scene3 is unavailable

By the rules dubbing uses only scene3. When scene3 is unavailable, this model can be used for dubbing this one time, and the user is told that the model was switched. Whether to switch and how is decided by the platform that uses the voice pack: the platform's adapter can switch by itself, or the platform's own skill can decide (for example the agent follows that skill, switches to this model and calls again, and the adapter calls only the model it is told to). The base part does not switch models by itself.

- **What counts as unavailable**：there is no scene3 on the platform; or scene3's service itself is down (5xx, timeout, service paused).
- **What does not count**：scene3 rejects this request (4xx, for example moderation rejection or wrong parameters). Report the error as it is, and do not switch models.
- **After the switch, the same character's voice differs from the one scene3 gives**：the two models each clone from the reference, and what comes out is not the same voice.[^b3]
- **Write specific instructions too.** This model accepts whole-sentence instructions (the "excited, happy" and "very slow" below are both written as instructions): in the instruction write how this particular line is to be read, and do not write summarizing labels such as "with a bit of a Sichuan accent" or "the tone of a news broadcast" (`scene3.md`「What to write」first item).
- **Emotion instructions mostly have no effect on a clone**[^b4]; the other items are below.
  - Emotion: the instruction "兴奋、开心" (excited, happy) was not judged to have an effect by the model (2026-10-30, lead, nobody has listened to it, the measurement by program is only a reference); the platform declaration also says an emotion instruction had no measurable effect in the tests. The instruction "悲伤、低落" (sad, low) and the tag `[sad]` were not verified.
  - Free-description square-bracket cues in the middle of a sentence, like those of scene3: tried once on a clone in an A/B on 2026-11-05 (one English line, three cues, one at the start and two in the middle): the two in the middle were read out as lines (the audio-listening model's transcription had "amused, a smile in her voice" and "softer, a little wistful" both times), and the one at the start was not heard being read out either time (model transcription, nobody has checked it). Synthesized only once.
  - On a clone: the instructions "非常缓慢" (very slow) and "非常快" (very fast), the tags `[very slowly]` and `[very fast]` (speed, measured by duration), and the pause `<break>` inside `<speak>` were measured to work (readings); the tags `[laughing]`, `[giggles]` (laughter) and `[sighing]` (sighing) the model judged audible (lead; the trap check passed, nobody has checked it, a dedicated model is only a reference); the pronunciation `<phoneme>` inside `<speak>` the model judged was read as the marked sound (nobody has checked it). All measured on 2026-10-30 and 31.
- **Write pronunciations as characters, not as inline phoneme tags.** Inline phoneme tags (`<|phoneme_start|>…<|phoneme_end|>`, `references/markup.md`「Angle-bracket tags」) are read as noise on this model: for a word whose reading needs to change, write it as characters that are read with that sound, or put it into the pack's pronunciation lexicon and let the platform convert it to the form the model accepts.[^b5] The `<phoneme>` inside `<speak>` above is a different way of writing, not this one.
- **Every passage sent to dubbing has at least 15 characters.** The text this model accepts when dubbing is at least 15 characters (code points; square-bracket cues do not count), so a short exclamation or reply ("嗯。", "走！", Chinese examples: "Mm.", "Go!") sent alone for dubbing cannot be synthesized: when writing the script, merge it into the previous or next line ("嗯。我知道了，你先回去吧。", "Mm. I understand, you go back first."), and merging does not change its manner or emotion. Where the platform declares this lower limit as the adapter's `limits.minChars`, `dub` merges a line shorter than it into the next line, records the ones that cannot be merged as `text_too_short` and does not call (`references/dub.md`「One request per passage」›「Ones shorter than the minimum are still merged.」); what `dub` counts is also the characters that are read out, and square-bracket cues do not count; merge first, and the cues of these lines are still written in their own places.[^b6]
- **Reference: a clone uses the reference audio itself.** For a pack made through an acted passage (a library voice, or a voice designed earlier), the pack's reference is the passage scene3 dubbed, and when switched to this model what is cloned is also that, not the voice it was dubbed from. Whether the model itself accepts reference text and how many segments it accepts were not checked; how many segments the platform accepts and whether there is a place for reference text is in the platform's adapter. The reference must be at least 3 seconds[^b7]. Whether the model itself accepts speaker markers was also not checked, and it is treated as not[^b8]: a scene with several people can only be done as one request per line and then joined.
- **Cross-language speech has an accent.** On 2026-11-05, 4 English-speaking voices said the same Chinese sentence, and all 4 clones of this model had an accent (for scene3's readings see `scene3.md`「Cross-language and accent」). One take, only one person listened, a small amount. On 2026-11-06 it was used to read English from a Japanese reference, and that was handed to scene3 as the English reference segment to dub English; the listener said "the timbre loss is a bit much", and judged it not as good as dubbing across languages directly with scene3 (same section).
