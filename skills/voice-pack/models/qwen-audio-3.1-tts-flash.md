# qwen-audio-3.1-tts-flash

This model is only for designing a voice: it designs a new voice from a description and reads out a design audition text. It is not used for dubbing; dubbing always uses scene3 (`scene3.md`). The audition that was designed and locked is only raw material: scene3 dubs an acted passage from it, and that passage is the pack's reference and default segment (`references/make-pack.md`「Making a pack from a designed voice」). When adding a reference in another language to a pack, it is only an option: on a platform that can name the model, the user may choose to first have it read a passage in this language from the pack's original reference and then use that as the reference; by default it is not used, and scene3 dubs across languages (`references/character-voice.md`「Add a reference segment in this language」; for the readings see `scene3.md`「Cross-language and accent」).

This file only says how to use the model itself and is not tied to a platform; limits a platform adds are written in that platform's adapter. The last section, "Fallback when scene3 is unavailable", covers what you need to know when dubbing is temporarily switched to this model. The source of a claim is written as in `scene3.md`「How the source is written.」; the platform declarations in this file were read on 2026-10-29.

## What it accepts

- One description and one design audition text, producing audio that reads out the audition text. Source: platform declaration.
- The description is written only in Chinese or English, at most 500 characters; the design audition text is 15 to 200 characters. Source: vendor documentation (this model's parameter table).
- With the same description, the voice designed may differ each time; the vendor's guide suggests designing several candidates first and picking after listening. The flow in this version designs one at a time and does not design several to pick a good one; if the user is not satisfied after listening, they ask to "switch to another" (`references/character-voice.md`「Finishing a round without asking, and switching to another」). Source: the vendor's voice design guide.
- The same `seed` does not guarantee the same voice. Source: platform declaration (The same seed does not reproduce the same audio).

## Dimensions of a description

The vendor's voice design guide says "the following dimensions can be combined to write a voice description" (a Chinese sentence); the table header is "description examples", and it does not say only the words in the table may be used; its own description examples use wording outside the table ("带有明显的上扬语调", with a clearly rising intonation; "说话略带稚气", speaks with a slightly childlike touch). The guide does not mention accent or breathiness, and says neither that they can be written nor that they cannot; the texture of the timbre has only a few words, in the "features" row and in the examples (husky, deep and resonant, "音色低沉有磁性", a deep, magnetic timbre), and things like rough and chest resonance are not mentioned. Source: the vendor's voice design guide (original text read on 2026-11-07; this model is among the models it supports).

For a description, use only the four rows gender, age, pitch, and features as the base, and then write what this voice's timbre is like concretely: the texture of the timbre (husky, rough, chest resonance, breath) and accent (write concrete features, see the accent item under "How to write a description"). Do not write the three rows speed, emotion, and purpose: speed and emotion are the manner of speaking, and purpose is a summarizing label (see "How to write a description" for all of these).

The table below gives the guide's original example words, which are Chinese because the description is written in Chinese or English; the English glosses are added here.

| Dimension | Example (original text of the guide) |
|---|---|
| gender | 男性、女性、中性 (male, female, neutral) |
| age | 儿童 (5-12 岁)、青少年 (13-18 岁)、青年 (19-35 岁)、中年 (36-55 岁)、老年 (55 岁以上) (child 5-12, teenager 13-18, young adult 19-35, middle-aged 36-55, old 55 and above) |
| pitch | 高音、中音、低音、偏高、偏低 (high, medium, low, somewhat high, somewhat low) |
| speed | 快速、中速、缓慢、偏快、偏慢 (fast, medium, slow, somewhat fast, somewhat slow) |
| emotion | 开朗、沉稳、温柔、严肃、活泼、冷静、治愈 (cheerful, steady, gentle, serious, lively, calm, soothing) |
| features | 有磁性、清脆、沙哑、圆润、甜美、浑厚、有力 (magnetic, crisp, husky, round, sweet, deep and resonant, powerful) |
| purpose | 新闻播报、广告配音、有声书、动画角色、语音助手、纪录片解说 (news broadcast, advertising voice-over, audiobook, animation character, voice assistant, documentary narration) |

This table is for writing design descriptions; it is not the same thing as the age and timbre tags that the voice library puts on recordings, and the two scales are used separately.

## How to write a description

- **Write only the timbre, one or two sentences, within 500 characters**：gender, a specific age, the height of the voice, the texture of the timbre (husky, rough, chest resonance, breathy voice); write accent only if the character's materials state it clearly or the user wants it, following the accent item below. Always write gender and age, never leave them out, following the character's materials; if the materials do not state gender and it cannot be seen from the name or description, see `references/character-voice.md`「Finishing a round without asking, and switching to another」. Do not write the manner of speaking: speed, rhythm, pauses, how the pitch rises and falls, tone of voice, attitude, laughter. The manner of speaking is not lost; where it goes is in `references/character-voice.md`「A designed voice: the description」 (speed, rhythm, pauses, and laughter go into the pack's dubbing guidance; expressiveness, tone, and attitude are written as the acting direction of the default segment and the audition line). Do not write identity, occupation, or experience either ("is a ship captain", "has been forging iron for years"): these are summarizing labels of a character setup, see the first item of `scene3.md`「What to write」; write the kind of voice you want as what its timbre is like concretely (source: requirement, see that item). The source for writing only the timbre and not the manner of speaking: on 2026-11-09 one person listened (settled), to two characters (a 50-year-old ship captain and a 60-year-old blacksmith, both male voices), a pair for each, all auditions straight out of the design step, each requested only once, not picked: A is the original way of writing (a description of several sentences that wrote the manner of speaking above; the audition text also in the original way), and B changes both (the description writes only the timbre, the original text is in "Example descriptions" below; the audition text changed to the way a person says it face to face, see "Design audition text"). Both B were better than A; the blacksmith's B was better (nobody asked what it was still missing), and the captain's B was still not enough (the problem the listener picked: the lines do not sound like something a person says, the rhythm drags, the pauses are odd). The two changes were made together, and the two cells that changed only the description or only the audition text were not listened to, so which one did the work cannot be separated: "changing only the description would also be better" is an inference. Only these two Mandarin-speaking, middle-aged and older male characters were listened to; that young, female, accented, or other-language characters should be written the same way is also an inference.
- **An earlier run (2026-11-07), when descriptions still included speaking manner**：6 characters, 3 ways of writing (A: one sentence using only words from the original table (read on 2026-10-26; the words differ slightly from the table above), with a flat audition text; B: several sentences writing gender, age, pitch and expressiveness, speed and rhythm, texture of the timbre, accent, and attitude, with a flat audition text; C: a description like B, with an audition text in the character's tone), each designed 4 times, 72 times in all. C was chosen then; the descriptions of B and C were more concrete than A and also wrote the manner of speaking, and which of these brought the differences below cannot be separated; after the listening of 2026-11-09 (the previous item), the description was changed to write only the timbre. The data of that run:
  - One person listened blind to the audition lines of 4 characters: two per character, one the highest model-judged score among A's 4 and one the highest among the 8 of B and C (C for 3 characters, B for 1), shuffled in order, and while listening they knew only that one was the old way of writing and one was the new way. After seeing the answer, C was chosen. B and C were not listened to side by side; it was listened to only this once.
  - Lead, model-judged whether it fits the character and whether it has character (it judges good or bad, see the measured item in `scene3.md`「How the source is written.」): at the audition step, C was higher than A and B for all 6 characters (fits the character 7 against 4 and 4, character 6 against 4 and 5); the model can hear the catchphrases spoken in the audition, so part of this difference may be the words and not all the sound. After the pack was made, the model-judged scores of the scene3 passage and the audition line did not show a difference among the three (lead). flash roughly does six or seven tenths of what the description says, and what it often cannot do is accent, huskiness, chest resonance, and rhythm (also model-judged, nobody has checked it).
  - Speaker similarity (different characters of the same gender, lower is better separated): for the flash audition, B was 0.061 lower than A (corrected p=0.005), and C was 0.024 lower than A, not significant; at the scene3 passage, the differences among the three were all not significant (`scene3.md`「Reference segments」). The clearest pair was two female voices, 26 and 73 years old, whose similarity at the scene3 passage was A 0.70, B 0.54, C 0.38 (the same recording compared with itself is about 0.85).
- **Example descriptions** (the two B that were listened to in the first item, original text): "五十岁的男人，嗓音偏低，胸腔共鸣厚，略带沙哑，是个船长。" (A 50-year-old man, rather low voice, thick chest resonance, slightly husky, is a ship captain.) "六十岁的男人，常年打铁，嗓音低沉，粗粝沙哑，带一点气声。" (A 60-year-old man, has forged iron for years, deep voice, rough and husky, with a little breath.) In the original text, "是个船长" and "常年打铁" are identity and experience, which the first item says not to write; written by the rule it is "五十岁的男人，嗓音偏低，胸腔共鸣厚，略带沙哑。" and "六十岁的男人，嗓音低沉，粗粝沙哑，带一点气声。"; the two with this half sentence removed were not listened to, and what was listened to had it. The captain's B was still not enough overall (the first item), whether the difference lies in the description or in the lines not being separated, so it is not a model to copy. The captain's A originally also wrote "说话慢，一句话分两三口气说完……语气从容、憨厚，说到好笑的地方自己先笑出声……态度热络、不催人" (speaks slowly, finishing a sentence in two or three breaths ... an unhurried, honest tone, laughing first at the funny parts ... warm, never rushing people); none of this is in B, and where it went is in the first item. For a character with an accent, after the timbre add one or two sentences of the accent's features (as recorded in the pack's dubbing guidance, `references/character-voice.md`「Features of an accent」), and do not write the name of the accent; a description with an accent written this way has not been listened to.
- **Age**：take a band from the table, then write a specific age; for a character under 30, write the age four or five years higher, still inside the character's age band. A designed young female voice is often judged younger than the description by the model and sounds like a teenager; with the age written a bit older there were fewer that were too young, while those that only changed pitch, features, and purpose were not fewer (model-judged, nobody has checked it; only 4 of each kind, read as a direction, not counted as measured to work). Source: measured on 2026-10-30, 4 voices per way of writing, model-judged (only asking whether it resembles the person the character's materials describe; the age heard, nobody has checked it): of 4 with the original way of writing, 3 were too young, and with the pitch changed to "medium", the features changed to "round", and the purpose changed to "audiobook" it was still 3, with "pitch rather low" 4, and with about 28 years old written 1. It did not pass the trap check, and only young female voices were tested.
- **Do not write the purpose**：the purposes in the table (news broadcast, audiobook, animation character and the like) are the names of genres and occasions and are summarizing labels (`scene3.md`「What to write」first item); write the kind of voice you want as what its timbre is like concretely (the height of the voice, the texture of the timbre). The 6 characters of 2026-11-07, whose descriptions of several sentences did not write a purpose, were not compared by themselves against ones that wrote a purpose. Measured on 2026-10-31, the same design audition text designed 4 times each, model-judged (nobody has checked it): of 4 that wrote "audiobook", 3 were said to be too young, and of those that wrote "animation character", 1; with only 4 of each, read it as no difference can be told apart.
- **Do not write words like reading aloud or announcing.** Words like reading aloud, announcing, commentary, narration, storytelling, performing, and dramatic pull the voice toward an announcer tone or a performing tone, so do not write them; if that is exactly his job (a news anchor, a documentary narrator, a bedtime-story teller), the description still writes only the timbre and not the names of such occupations and genres (`scene3.md`「What to write」first item); how he speaks at work (articulation, speed and rhythm, expressiveness) is the manner of speaking and does not go into the description, and where it goes is the same as in the first item (articulation and expressiveness are likewise written as acting direction). This item is an inference, and nobody has listened to it: the lead is another measurement of 2026-10-25, on the previous design model, where the model judged whether it sounds like reading aloud (it judges whether it is affected, see the measured item in `scene3.md`「How the source is written.」): with words like "讲故事时带一点戏剧性" (a little dramatic when telling a story) in the description and lines in the old, written-language tone, 7 of 16 answers said "reading aloud"; after it was changed, 0 of 30. On this model it carries no weight. Even a negation ("not an announcer tone") is not written: it was not tested, and it is handled as if it would bring the word in.
- **Write features that can be heard** (the height of the voice, the texture of the timbre, the use of breath and the like). Evaluative words such as "pleasant" and "natural and friendly" do not say what the voice sounds like, so replace them with features; write several dimensions in combination, and remove repeated near-synonyms; describe the qualities of this voice itself, and do not name a person for it to imitate. Source: the vendor's voice design guide.
- **Accent, huskiness, breathiness, larynx position and tightness written into the description are not guaranteed**：write accent only if the character's materials state it clearly (or the user wants it), and write what it sounds like; identity, occupation, and experience are still not written (source: requirement, said on 2026-11-09, in answer to exactly this item: "Q5 行。但是这个只影响配音相关的对吧", "Q5 fine. But this only affects dubbing, right?"). Write the accent as the features of this accent recorded in the pack's dubbing guidance (`references/character-voice.md`「Features of an accent」), and do not write the name of the accent (`scene3.md`「What to write」first item); whether writing it into the description by features produces it has not been tested. In the measurement of 2026-11-07 (the item "An earlier run"), when written into the description the model-judged scores did not show a harm (lead; these were not measured separately), but flash often cannot do it (model-judged, nobody has checked it); for a character with a Dublin accent (B and C wrote it in the description, A did not), the model mostly heard a British or Scottish accent and only occasionally heard a bit of an Irish tone (model-judged, nobody has checked it). Throat position, tightness, breathiness, and huskiness are at the same time still written into the how-to-perform part of the dubbing guidance; for how a character's own accent is written when dubbing, see `scene3.md`「Cross-language and accent」, and for dialect words in lines see `references/character-voice.md`「Emotional lines」; for an accent brought by a reference in another language, see the section on language and accent in the same file. If you must have a certain accent, a recording with that accent is mostly more accurate: inference, not measured.
- **Speed does not go into the description.** Speed is the manner of speaking and, following the first item, is written into the how-to-perform part of the dubbing guidance. The readings are still kept: the instruction "very slow" works and the designed voice reads more slowly; "very fast" does not work (measured on 2026-10-30).

## Design audition text

- **Length**：this model accepts 15 to 200 characters ("What it accepts" above). How long it should be when read aloud, the rule is in `references/character-voice.md`「Design audition text when designing」; after locking, scene3 uses it as the reference to dub the acted passage: for scene3 a reference of 1 to 20 seconds per segment is suitable (`scene3.md`「Reference segments」), and the clone guide of this model's family suggests 10 to 20 seconds and complete sentences.
- **What to write**：a passage the character says in their own tone to the person listening, face to face, not a self-introduction; how to write it is in `references/character-voice.md`「Design audition text when designing」「Who the script is addressed to: words spoken face to face to the listener」. It does not go into the pack that is handed out: the pack's default segment is the passage scene3 dubs from it. The items below are the reasons on this model, and each says whether it is a reading or an inference.
- **Write what a person would say face to face** (the rule and the original text that was listened to are in `references/character-voice.md`「Design audition text when designing」): Source: on 2026-11-09 one person listened (the first item of "How to write a description", settled): both changes were better than the original, the captain's was still not enough and is not a model to copy (`references/character-voice.md`, same section); the audition text and the description were changed together, so which one did the work cannot be separated, and "changing only the audition text would also be better" is an inference. Only two Mandarin-speaking, middle-aged and older male voices were listened to; that young, female, accented, or other-language voices should be written the same way is also an inference. There is a model judgment going the opposite way for filler words on a young female voice (in the next item, the run of 2026-10-30 and 31, where they were said to be too young; the age heard, nobody has checked it), and the two ways of writing were not compared on a young female voice: for a young female voice (under 30), use only the filler words in the character's materials and do not add any (the rule is in `references/character-voice.md`, same section). The earlier lead is the measurement of 2026-10-25 (the same as the item "Do not write words like reading aloud or announcing" in "How to write a description", model-judged whether it sounds like reading aloud), which carries no weight on this model.
- **Use the character's own tone, with catchphrases and sentence endings from the character's materials** (the rule is in `references/character-voice.md`「Design audition text when designing」): Source: measured on 2026-11-07 (C of the item "An earlier run" in "How to write a description"; for characters under 30 the age was written higher following the item "Age"), model-judged (the age heard, nobody has checked it): C was heard younger in 3 of 24, A in 9, B in 11; of 4 for a 26-year-old young female voice 1 was heard younger (as 21 to 23 years old), and none was heard as a teenager; designed 4 times for the same character, C was the steadiest (lead: the model-judged fit-to-character score of the scene3 passage varied by 1 from one to another, A by 2.3). The run of 2026-10-30 and 31, "of 4 audition texts with '哎呀', '嘛', '就行啦' (interjections and particles), 3 were said to be too young" (model-judged, the age heard, nobody has checked it), tested only a young female voice, and the description was in the old way too; this time it was not retested: the only young adult female voice this time (26 years old) had no such particles in the materials, and C's audition text had "所以呢？" and "讲重点" ("So?" and "Get to the point"). For a young female voice whose materials have words like "哎呀" and "嘛", whether bringing them in would make her heard younger has not been tested. This time (2026-11-07), C's audition text was said to a person in the situation of the materials and gave the name (for example `哎老弟，坐坐坐！我赵大海，哈尔滨的……`, a Chinese example line: "Hey, little brother, sit, sit! I'm Zhao Dahai, from Harbin ..."); whether one written as in `references/character-voice.md`「Who the script is addressed to: words spoken face to face to the listener」, said to the listener, is heard younger has not been measured.
- **Auditions produced by design are mostly read flat.** Using it as the reference, scene3 mostly also acts flat (inference: only one character on the first page of auditions was listened to, by one person, `scene3.md`「Reference segments」). So it is only raw material and is not used directly as the pack's reference; in the passage dubbed from it, the acting is brought out by the cues written at each place where the manner changes (`references/character-voice.md`「Default segment: a passage the character says naturally, with acting」).

## Fallback when scene3 is unavailable

By the rules dubbing uses only scene3. When scene3 is unavailable, this model can be used for dubbing this one time, and the user is told that the model was switched. Whether to switch and how is decided by the platform that uses the voice pack: the platform's adapter can switch by itself, or the platform's own skill can decide (for example the agent follows that skill, switches to this model and calls again, and the adapter calls only the model it is told to). The base part does not switch models by itself.

- **What counts as unavailable**：there is no scene3 on the platform; or scene3's service itself is down (5xx, timeout, service paused).
- **What does not count**：scene3 rejects this request (4xx, for example moderation rejection or wrong parameters). Report the error as it is, and do not switch models.
- **After the switch, the same character's voice differs from the one scene3 gives**：the two models each clone from the reference, and what comes out is not the same voice. Inference, not listened to side by side.
- **Write specific instructions too.** This model accepts whole-sentence instructions (the "excited, happy" and "very slow" below are both written as instructions): in the instruction write how this particular line is to be read, and do not write summarizing labels such as "with a bit of a Sichuan accent" or "the tone of a news broadcast" (`scene3.md`「What to write」first item).
- **Emotion instructions mostly have no effect on a clone** (inference: the platform declaration, plus the model did not judge any effect, a lead); the other items are below.
  - Emotion: the instruction "兴奋、开心" (excited, happy) was not judged to have an effect by the model (2026-10-30, lead, nobody has listened to it, the measurement by program is only a reference); the platform declaration also says an emotion instruction had no measurable effect in the tests. The instruction "悲伤、低落" (sad, low) and the tag `[sad]` were not verified.
  - Free-description square-bracket cues in the middle of a sentence, like those of scene3: tried once on a clone in an A/B on 2026-11-05 (one English line, three cues, one at the start and two in the middle): the two in the middle were read out as lines (the audio-listening model's transcription had "amused, a smile in her voice" and "softer, a little wistful" both times), and the one at the start was not heard being read out either time (model transcription, nobody has checked it). Synthesized only once.
  - On a clone: the instructions "非常缓慢" (very slow) and "非常快" (very fast), the tags `[very slowly]` and `[very fast]` (speed, measured by duration), and the pause `<break>` inside `<speak>` were measured to work (readings); the tags `[laughing]`, `[giggles]` (laughter) and `[sighing]` (sighing) the model judged audible (lead; the trap check passed, nobody has checked it, a dedicated model is only a reference); the pronunciation `<phoneme>` inside `<speak>` the model judged was read as the marked sound (nobody has checked it). All measured on 2026-10-30 and 31.
- **Write pronunciations as characters, not as inline phoneme tags.** Inline phoneme tags (`<|phoneme_start|>…<|phoneme_end|>`, `references/markup.md`「Angle-bracket tags」) are read as noise on this model: for a word whose reading needs to change, write it as characters that are read with that sound, or put it into the pack's pronunciation lexicon and let the platform convert it to the form the model accepts. Source: measured, run on 2026-11-10 in a dev environment where another platform connects voice packs; one phoneme tag in a line was read as a stretch of noise; only this once, and who judged it was not recorded. The `<phoneme>` inside `<speak>` above is a different way of writing, not this one.
- **Every passage sent to dubbing has at least 15 characters.** The text this model accepts when dubbing is at least 15 characters (code points; square-bracket cues do not count; the design audition text is also at least 15 characters, "What it accepts" above), so a short exclamation or reply ("嗯。", "走！", Chinese examples: "Mm.", "Go!") sent alone for dubbing cannot be synthesized: when writing the script, merge it into the previous or next line ("嗯。我知道了，你先回去吧。", "Mm. I understand, you go back first."), and merging does not change its manner or emotion. Where the platform declares this lower limit as the adapter's `limits.minChars`, `dub` merges a line shorter than it into the next line, records the ones that cannot be merged as `text_too_short` and does not call (`references/dub.md`「One request per passage」›「Ones shorter than the minimum are still merged.」); what `dub` counts is also the characters that are read out, and square-bracket cues do not count; merge first, and the cues of these lines are still written in their own places. Source: platform declaration (the lower limit stated when another platform connected this model for dubbing; when the service rejects, what it says is "requires input of at least N Unicode code points"); "merge into the previous or next line" is a requirement, a general way of writing said on 2026-11-12.
- **Reference: a clone uses the reference audio itself.** For a designed voice, the pack's reference is the passage scene3 dubbed from the audition, and when switched to this model what is cloned is also that, not the audition from the design. Whether the model itself accepts reference text and how many segments it accepts were not checked; how many segments the platform accepts and whether there is a place for reference text is in the platform's adapter. The reference must be at least 3 seconds: measured on 2026-10-28 on the vendor's interface directly, 2.5 seconds was rejected and 3.0 seconds was built. Whether the model itself accepts speaker markers was also not checked, and it is treated as not (inference): a scene with several people can only be done as one request per line and then joined.
- **Cross-language speech has an accent.** On 2026-11-05, 4 English-speaking voices said the same Chinese sentence, and all 4 clones of this model had an accent (for scene3's readings see `scene3.md`「Cross-language and accent」). One seed, only one person listened, a small amount. On 2026-11-06 it was used to read English from a Japanese reference, and that was handed to scene3 as the English reference segment to dub English; the listener said "the timbre loss is a bit much", and judged it not as good as dubbing across languages directly with scene3 (same section).
